# 💼 赛博社畜体测模拟器 (Cyber Worker Fitness Simulator)

一个极其硬核、充满现实压迫感的回合制人生模拟/增量游戏。

在这个被设定为**公转周期 336 天（12个月，每月28天）**的虚拟星球上，你将从 20 岁起步，一直打工、训练到 50 岁强制退役。你不仅要面对《学生体质健康标准》的残酷考验，还要努力生存。

## 🌟 核心机制 (Features)

*   **⏱️ 336天异星历法**：完美划分的 28 天/月。实行“上五休二”，但每月的第 4 周固定触发“上三休四”的带薪长假。
*   **💼 双职业生存**：你可以选择“脑力劳动”或“体力劳动”。体力劳动赚得多，但体力上限极低且每天下班都会累得半死（积累高额疲劳值）。
*   **💸 微观经济学模拟**：
    *   **动态富人税**：每天的生活费为 `max(50, 总资产 * 0.2%)`，钱越多扣得越狠。
    *   **复利银行**：提供每天 0.02% 的存款利息，帮你抵抗通胀。
    *   **年底暴富**：年度体测采用“速算扣除数”计算年终奖，考得越高，奖金呈指数级爆炸。
*   **🩸 疲劳与超量恢复**：真实运动生理学。疲劳值过高强行训练会“肌肉拉伤”掉属性；休息充分后可触发“超量恢复”获得双倍收益。
*   **🩺 病根与医疗系统**：
    *   长期打工会在体内积累“病根”，病根会严重降低你的日常训练收益。
    *   过度劳累会触发**强制送医**（扣 50% 工资，罚款 8000）。
    *   你可以花钱**主动就医**（扣 10% 工资），清空病根，继续打工。

## 🛒 赛博商城 (Shop)
打工赚来的钱，可以用来购买对抗残酷机制的道具：
- 🏠 **市郊廉价租房**：降低每日基础生活费。
- 📱 **降噪隔音耳塞**：工作日体力上限 +5。
- 🦿 **外骨骼护腿**：降低体力劳动带来的额外疲劳。
- ☕ **赛博浓缩液**：立刻清空所有疲劳值。

## 🛠️ 技术栈 (Tech Stack)
- **后端**：Node.js + Express
- **数据库**：SQLite (better-sqlite3) - 存储真实的体测标准与玩家存档
- **前端**：原生 HTML / CSS / JavaScript（无框架，极致纯粹）
- **数据可视化**：原生 DOM 操作与动态样式计算

## 🚀 如何运行 (How to run)
1. 克隆仓库并安装依赖：`npm install`
2. 初始化数据库（灌入体测标准）：`node initDB.js`
3. 启动服务器：`node server.js`
4. 双击打开 `index.html` 即可开始受苦。
