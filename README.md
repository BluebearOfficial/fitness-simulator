# 🏃 体测模拟器 (Fitness Simulator)

一个硬核的、基于真实《国家学生体质健康标准（大四男生）》的回合制放置/模拟游戏。

## 🌟 核心特性
- **真实物理引擎**：训练不是简单的加数字，力量训练会增重，耐力训练会减脂，BMI 会实时计算并影响总成绩。
- **日历回合制**：没有无脑的离线挂机，每一次【结束今天】都需要精打细算地分配体力。
- **肌肉超量恢复**：引入真实的运动生理学机制。疲劳度归零且休息足够时，下一次训练收益直接翻倍！
- **严酷的软上限**：单项成绩突破 60 分和 80 分后，训练收益将遭遇断崖式衰减，逼你寻找新的突破点。
- **人类极限锁**：无论你点数多高，50 米极限锁定在 5.56 秒，1000 米锁定在 2 分 11 秒，致敬真实世界纪录。
- **50岁强制退役**：人的青春是有限的。从 20 岁到 50 岁，你能留下怎样的体测传说？

## 🛠️ 技术栈
- **后端**：Node.js + Express
- **数据库**：SQLite (better-sqlite3) 存储 135 条硬核体测标准
- **存档**：纯本地 JSON 持久化
- **前端**：原生 HTML / CSS / JavaScript (零框架，极致纯粹)

## 🚀 如何运行
1. 克隆仓库并安装依赖：`npm install`
2. 初始化数据库（灌入标准数据）：`node initDB.js`
3. 启动服务器：`node server.js`
4. 双击打开 `index.html` 即可开始受苦。
